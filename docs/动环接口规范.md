# 机房动环（动力环境）监控对接规范 v1.0

> 目标：把 UPS 电源、温湿度、浸水、烟感、报警、供电电流电压等**动环测点**接入本平台，
> 同时提供**真实可对接的接口**（Modbus TCP / SNMP / MQTT / HTTP-JSON 网关 + WebSocket 推送），
> 在无真实设备时用内置模拟器等价跑通。
>
> 术语：**南向**=平台↔动环设备/厂家系统；**北向**=本平台↔上级监控/第三方平台。

## 0. 架构（浏览器不能直接开 TCP/SNMP，必须有网关）

```
┌──────────────┐   Modbus TCP / SNMP v2c / MQTT / HTTP-JSON   ┌──────────────────┐
│ 动环设备/厂家 │ ◀─────────────────────────────────────────── │  动环网关(南向)   │
│ UPS·空调·温湿度│                                              │ tools/gateway/    │
│ 浸水·烟感·配电 │ ───────────────────────────────────────────▶ │  Node，零依赖     │
└──────────────┘       采集/轮询/解析/归一化                    └────────┬─────────┘
                                                                        │ WebSocket(JSON) + HTTP
                                                              ┌─────────▼─────────┐
                                                              │ 前端 src/donghuan.js│
                                                              │ 点表·报警引擎·北向  │
                                                              └─────────┬─────────┘
                                                                        │ IDC.bus 事件
                                                    ┌───────────────────┼───────────────────┐
                                                    │                   │                   │
                                              HUD 动环页            3D 传感器点位          语音助手
```
- 浏览器侧**只连网关**（`ws://localhost:<port>/dh`）；网关不可用时 `src/donghuan.js` 自动降级为**内置本地模拟器**（双击 index.html 也能演示）。
- 网关自带**设备模拟器**：在没有真实 UPS/烟感时，按同一套点表产生等价数据，`GET /dh/inject` 可注入报警。

## 1. 设备与测点模型（网关与前端共用，字段同名同义）

### 1.1 设备 Device
| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 设备唯一编号，如 `UPS-01`、`TH-A01`、`WD-A1`、`SM-07`、`MDB-1` |
| name | string | 中文名，如「A 区 UPS-01」 |
| type | enum | `ups` \| `ac`（精密空调）\| `th`（温湿度）\| `water`（浸水）\| `smoke`（烟感）\| `mdb`（配电/列头柜）\| `battery` \| `ats`（双电源切换） |
| zone | string | `A 区`/`B 区`/`C 区`/`电力间` |
| vendor / model | string | 厂家 / 型号，如 `华为 UPS5000-E 200kVA` |
| protocol | enum | `modbus-tcp` \| `modbus-rtu` \| `snmp` \| `mqtt` \| `http-json` \| `sim` |
| ip / port / slaveId | - | 南向连接参数（sim 填 `-`） |
| online | bool | 网关判定（连续 3 个周期无响应 → false） |
| lastRt | ms | 最近一轮采集耗时 |
| loc | {x,y,z} | 3D 坐标（米，用于三维定位；烟感在吊顶 y≈3.2） |

### 1.2 测点 Point
| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | `设备ID.点名`，如 `UPS-01.UA`、`SM-07.state` |
| devId | string | 所属设备 |
| name | string | 中文测点名，如「A 相输入电压」 |
| kind | enum | `ai`（模拟量）\| `di`（状态量）\| `do`（控制量，只读展示） |
| unit | string | `V` `A` `kW` `kWh` `℃` `%RH` `Pa` `min` ``（状态量空） |
| scale | number | 原始值 × scale = 工程值（Modbus 用） |
| addr | string/number | Modbus 寄存器地址（`4xxxx` 保持寄存器 / `3xxxx` 输入寄存器），或 SNMP 用 `oid` |
| oid | string | SNMP OID（如 `1.3.6.1.4.1.10001.1.2.1.0`） |
| mqtt | string | MQTT topic（如 `idc/ups/01/ua`） |
| hi / hiHi / lo / loLo | number | AI 报警阈值（可空） |
| deadband | number | 回差，防止抖动（默认量程 1%） |
| delay | number | 持续秒数确认（默认 3s） |
| bits | object | 状态量位定义：`{0:'正常',1:'报警'}` 或位图 `{bit:3, name:'旁路供电'}` |
| normal | number | DI 正常值（默认 0；invert 语义时用 `invert:true`） |
| invert | bool | DI 是否取反 |

### 1.3 报警规则（前端与网关一致实现）
- **AI 越限**：`v>hiHi → critical`；`v>hi → warning`；`v<loLo → critical`；`v<lo → warning`；带 `delay` 持续确认与 `deadband` 回差；恢复后写 `cleared` 并记录持续时长。
- **DI 变位**：`v!==normal`（`invert` 时相反）→ 报警；`smoke`/`water` 动作 = **critical**；`ups.bypass`/`ats` 异常 = warning。
- **通信中断**：设备 `online=false` 持续 >30s → `info` 级「通信中断」，恢复自动清除。
- **级别**：`critical(严重) | warning(一般) | info(提示)`。
- 报警对象：`{ id, pointId, devId, level, rule:'hiHi|hi|lo|loLo|di|offline', text, value, unit, state:'active|acked|cleared', ts, ackTs, clearTs }`。

## 2. 南向：设备与点表（首批接入清单）

| 设备 | 数量 | 协议 | 关键测点 |
|---|---|---|---|
| UPS（华为 UPS5000-E 200kVA） | 2 | modbus-tcp（slave 1/2） | 三相输入电压 UA/UB/UC、输入电流 IA/IB/IC、频率、三相输出电压/电流、负载率、电池电压、电池电流、后备时间、输入/输出/旁路开关状态、整流器/逆变器/电池/旁路故障、环境温度 |
| 精密空调 | 2 | modbus-tcp | 回风温湿度、送风温度、设定温度、压缩机/风机/加热/加湿状态、滤网堵塞、高/低压报警 |
| 温湿度（每排 2 点 + 电力间） | 12 | modbus-rtu（网关串口/或 modbus-tcp 转换器） | 温度（-20~60℃）、湿度（0~100%RH）、露点 |
| 浸水检测（绳式 + 点式） | 4+8 | modbus-tcp（多路 DI） | 各通道浸水状态（0 正常 / 1 浸水）、绳断线 |
| 烟感（吸顶） | 12 | modbus-tcp（多路 DI） | 烟雾状态、探头故障、污染度 |
| 低压配电/列头柜 | 2 | modbus-tcp | 三相相电压/线电压、三相电流、有功功率、功率因数、有功电能、频率、断路器位置、过流/过压/欠压报警 |
| 电池组 | 1 | modbus-tcp | 组电压、充放电电流、单体温差、内阻均值、SOH |
| ATS 双电源 | 1 | modbus-tcp | 主/备电源电压、当前工位、切换次数 |

> 真实项目请按厂家《通信协议手册》填 `addr/oid/mqtt/scale/bits`；本平台已把**点表做成可配置**，换厂家只改点表，不改代码。

## 3. 网关（南向采集）对外接口

### 3.1 WebSocket 推送 `ws://localhost:<port>/dh`（JSON 文本帧，一行一条）
```jsonc
// 建链后立即下发（点表 + 设备 + 网关信息）
{ "type":"hello", "gw":"dh-gw/1.0", "site":"上海一号数据中心", "t":1730000000,
  "devices":[ /* 见 §1.1 */ ], "points":[ /* 见 §1.2 */ ], "driver":"sim",
  "poll":{"interval":2000}, "protocols":["modbus-tcp","modbus-rtu","snmp","mqtt","http-json","sim"] }

// 周期数据（只发变化点 + 每 10 个周期全量）
{ "type":"data", "t":1730000001, "seq":42, "values":{ "UPS-01.UA":231.4, "SM-07.state":0, "TH-A01.temp":24.3 },
  "quality":{ "UPS-01.UA":"good" }, "full":false }

// 设备在线状态（变化时）
{ "type":"status", "t":..., "devices":{ "UPS-01":{"online":true,"rt":12} } }

// 报警（产生/确认/恢复）
{ "type":"alarm", "t":..., "alarm":{ /* 见 §1.3 报警对象 */ } }

// 事件/日志
{ "type":"event", "t":..., "event":{"kind":"connect|inject|info|error","text":"..."} }
```

### 3.2 HTTP 接口
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/dh/health` | 网关状态：`{ok,driver,uptime,poll,devices,points,clients,errors}` |
| GET | `/dh/points` | 点表 JSON（含 addr/oid/scale/阈值/bits），用于对点 |
| GET | `/dh/points.csv` | 点表 CSV（可直接交厂家/第三方对点） |
| GET | `/dh/snapshot` | 全量实时值快照 `{t, values, quality, online}` |
| GET | `/dh/alarms` | 当前活动报警列表 |
| POST | `/dh/inject` | 演示注入：`{"pointId":"WD-A1.ch1","value":1}` 或 `{"deviceId":"SM-07","action":"smoke"}` |
| POST | `/dh/driver` | 切换驱动：`{"driver":"sim|modbus-tcp|snmp|mqtt"}` |

### 3.3 驱动实现说明（`tools/gateway/`）
- `modbus-tcp.mjs`：功能码 03/04 读保持/输入寄存器，支持批量读、超时重试、异常码解析；按点表把 `addr/scale/type(int16/uint16/int32/float32/bit)` 解码。
- `snmp.mjs`：SNMP v2c GET/GETNEXT（BER 编解码），按 `oid` 取值；用于 UPS/空调厂家 SNMP 卡。
- `mqtt.mjs`：MQTT 3.1.1 订阅（`idc/#`），按 `point.mqtt` topic 映射；可直连 EMQX/自有 Broker。
- `http-json.mjs`：GET/POST 拉取厂家 JSON 接口（带 token/鉴权头配置）。
- `sim.mjs`：内置**设备模拟器**（默认驱动）：按点表生成带噪声/日周期/随机告警的真实感数据，支持 `inject` 强制置位。
- `server.mjs`：HTTP + WebSocket 服务（零依赖，自实现 RFC6455 握手与帧编解码），聚合上述驱动、跑采集循环、跑报警规则、对外暴露 §3.1/§3.2。

## 4. 北向接口（本平台向上级平台上报）
- `src/donghuan.js` 维护北向报文并在每次采集后更新：
```jsonc
{ "site":"上海一号数据中心", "ts":1730000001,
  "devices":[{"id":"UPS-01","online":true,"rt":12}],
  "alarms":[{"id":"...","level":"critical","point":"UPS-01.UA","text":"A 相输入电压过压","value":268.4,"unit":"V","state":"active","ts":...}],
  "metrics":{"onlineRate":0.98,"activeAlarms":4,"upsLoad":68,"batteryMin":22} }
```
- REST 风格路径约定（供第三方拉取/订阅）：`/north/metrics`（实时指标）、`/north/alarms`（活动报警）、`/north/points`（点表）、`/north/history?pointId=&from=&to=`（历史曲线）。
- 上报方式：`WS 推送` / `HTTP POST 周期上报` / `MQTT 发布`（三选一，配置在 `IDC.dh.northbound.config`）。

## 5. 前端模块 `src/donghuan.js` 契约（HUD / 3D / 语音都依赖它）
```js
IDC.dh.init({ data, scene, hud, app })      // 建链：优先 ws://<host>:<gatewayPort>/dh，失败降级本地模拟
IDC.dh.devices / IDC.dh.points / IDC.dh.alarms          // 设备、测点(Map by id)、活动报警
IDC.dh.getDevice(id) / getPoint(id) / pointsOf(devId)    // 查询
IDC.dh.byType(type)                                      // 按类型取设备，如 byType('smoke')
IDC.dh.activeAlarms() / alarmsOf(devId)                  // 报警查询
IDC.dh.ack(id) / clear(id)                               // 确认 / 清除报警
IDC.dh.inject({pointId,value}) / trigger(devId, action)  // 演示注入（'water'|'smoke'|'overvoltage'|'offline'）
IDC.dh.setDriver(name)                                   // sim|modbus-tcp|snmp|mqtt|http-json
IDC.dh.gw                                                // 网关状态 {connected,driver,lastPoll,latency,interval,rate,errors}
IDC.dh.pointTable({format:'json'|'csv'})                 // 点表导出（对点用）
IDC.dh.northbound()                                      // 北向报文对象
IDC.dh.tick()                                            // 兜底轮询（本地模拟模式下由 app 调用）
```
**事件（`IDC.bus`）**：`dh:ready`（建链/降级完成）、`dh:data`（一轮数据）、`dh:alarm`（新增报警）、`dh:alarm:ack`、`dh:alarm:clear`、`dh:select`（`{devId,pointId}` 由 3D/列表点选触发）、`dh:inject`。

## 6. 三维点位与交互（scene3d）
| 类型 | 3D 表现 | 位置 |
|---|---|---|
| 烟感 | 吊顶白色小圆盘 + 红色 LED | 每 3m×3m 网格，y≈3.2m |
| 浸水 | 冷通道两端检测盒 + 地面细绳 | 通道端头 / 墙脚 |
| 温湿度 | 机柜门上方小盒（复用 `PROPS.sensor()`） | 每排首尾柜 + 电力间 |
| UPS/配电/电池 | 沿墙柜体（复用 `PROPS.ups/pduCabinet/battery`） | 后墙，对应设备 id |
- 报警时：该点位 `emissiveIntensity` 脉冲 + 地面红色光圈 + 浮空标签（点名 + 值）；
- 点击任意传感器 → `IDC.bus.emit('dh:select', {devId, pointId})`，HUD 打开对应详情；
- 新增 `IDC.scene.setSensorAlarms([{devId, level}])`、`IDC.scene.focusDevice(devId, opts)`。

## 7. HUD「动环监控」页（新页签）
- 顶部：接口状态条（驱动 / 连接 / 采集周期 / 最后采集 / 点位总数 / 丢包率）+ 4 KPI（设备在线率、活动报警、UPS 负载率、电池后备时间）
- 左：动环设备树（区域 → 类型 → 设备，带在线点/报警角标）
- 中：分区标签 —— `UPS`（三相电压电流表 + 负载率环形 + 电池组信息）/ `温湿度`（24h 曲线 + 分区柱图 + 越限标红）/ `浸水`（点位矩阵，绿/红，含绳断线）/ `烟感`（点位矩阵 + 污染度）/ `供配电`（回路电流电压表 + 功率/电能 + 断路器位置）
- 右：实时报警列表（级别色条、设备、测点、值、时间、确认/处置按钮）+ 点表速览（协议 / 地址 / OID / 阈值）
- 所有数值一律读 `IDC.dh`（禁止写死），随 `dh:data` 刷新。
