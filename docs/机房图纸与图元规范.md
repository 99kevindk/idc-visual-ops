# 机房图纸与图元规范 v1.0（图元库 / 2D 绘制 / 3D 扩展）

> 需求原话："以及机房图元元素，机房图形绘制，现有机房图形扩展等！"
> 目标：① 一套**机房图元库**（矢量符号，可扩展）② **2D 机房图纸的绘制与编辑**（平面图/俯视图，可导出）
> ③ 与**现有 3D 机房双向联动**，并支持把新增图元**扩展**到现有三维场景中。

## 0. 三个视图的关系

```
                    ┌──────────────────────────────┐
   3D 机房 (scene3d) │  真实数据源：                 │
        ▲            │  IDC.data.racks  42 台机柜    │
        │ 扩展/定位   │  IDC.dh.devices  39 台动环设备│
        │            │  src/pointtable.js  place 字段 │
   IDC.plan ◀────────┤                              │
   (2D 图纸/编辑器)   └──────────────────────────────┘
        │ 图纸 JSON / PNG / SVG 导出
        └─ 图元库 src/symbols.js（可注册扩展）
```
- **自动出图**：进入图纸页时按 3D 机房的真实坐标（`racks[].x/z`）与动环设备 `place` 生成平面图底图（机柜阵列、冷通道、电力间、空调、烟感、浸水、温湿度）。
- **图纸编辑**：拖动/旋转/增删图元、图层、标注、尺寸线；编辑结果保存在 `plan` 模型（localStorage），可导出 JSON/PNG/SVG。
- **扩展回 3D**：图纸里新增/修改的图元可通过 `IDC.scene.setExtras(list)` 同步到 3D 机房，成为真实三维物件（新增机柜/UPS/空调/烟感/灭火器/摄像头/隔断/桥架…）。
- **状态联动**：图纸图元可绑定机柜（`racks[]`）或动环设备（`IDC.dh`），实时显示状态色/值/告警脉冲；点击图元 → 3D 定位（`scene.focusRack` / `scene.focusDevice`）。

## 1. 图元库 `src/symbols.js`（**契约冻结**）

坐标与单位：**单位 mm**，俯视图，`+x` 向右、`+y` 向下；`draw()` 调用时 ctx 已平移到图元中心并按 `rot` 旋转、已按 `scale` 缩放，图元只需以自身中心为原点绘制。

```js
// 元数据
export const CATEGORIES = [ {id,name,color}, ... ];  // arch/rack/power/cool/safety/env/cable/annot
export const SYMBOLS = { [id]: SymbolDef };

SymbolDef = {
  id: 'rack.42u',            // 唯一 id，建议 `<类>.<型>`
  name: '服务器机柜',          // 中文名（图元面板显示）
  cat: 'rack',               // 分类 id
  w: 600, h: 1200,           // 默认外轮廓尺寸（mm）：w=平面宽, h=平面深
  fill: '#2b3138', stroke: '#7fd8ff',
  bind: 'rack' | 'dh' | null,// 可绑定的对象类型（null=纯图元）
  anchor: { x: 0, y: 0 },    // 图元绘制原点相对中心（默认中心）
  ports: [ {x:0,y:-h/2,dir:-90,name:'前门'} ],  // 连接点（可空）
  params: [ {key:'door', name:'开门方向', type:'enum', options:['N','S','E','W'], def:'S'} ],
  draw(ctx, it, env)         // 必需：矢量绘制
};

env = {
  scale,                      // px / mm
  status: { state:'normal'|'alarm'|'offline'|'maintain', level:'critical'|'warning'|'info', pulse:0..1 },
  value: '24.3℃',            // 绑定对象的实时值文本（无绑定为 null）
  label: true,                // 是否显示文字
  selected, hover, locked,
  time                        // 帧时间（做脉冲/闪烁用）
};

// 对外函数
export function drawSymbol(ctx, id, it, env)     // 统一绘制入口（未知 id 画占位框 + 问号）
export function listSymbols(cat)                 // 列出（图元面板用）
export function iconCanvas(id, px)               // 返回 <canvas> 缩略图（图元面板用）
export function register(def)                    // ★ 扩展：注册自定义图元
export function registerFromSvg(id, meta, pathD) // ★ 扩展：用 SVG path 数据注册自定义图元
export function has(id)
```

## 3. 绘制/编辑器 `src/floorplan.js` 契约

```js
IDC.plan.mount(el)        // 绑定容器（整页，含工具栏/图元面板/画布/属性栏）
IDC.plan.show() / hide()
IDC.plan.buildFromScene() // 依据 racks + pointtable 自动出图（保留用户已加图元）
IDC.plan.load(json) / toJSON() / save() / restore()
IDC.plan.exportPNG(name) / exportSVG() / print()
IDC.plan.addSymbol(symId, x, y)          // 放置图元（由面板拖拽或点击调用）
IDC.plan.select(id) / selectByRef(type, ref) / clearSelection()
IDC.plan.setZoom(z) / fitToScreen() / zoomToRef(type, ref)
IDC.plan.extended()                      // 返回"用户新增/修改的图元"（供 3D 扩展）
IDC.plan.applyExtras()                   // 调用 IDC.scene.setExtras(IDC.plan.extended())
```
**交互要求**：网格 + 吸附（10/50/100/500mm 可调）、平移（空格/中键拖动）、缩放（滚轮，0.1~10×）、单选/框选/多选、拖动移动、方向键微移、旋转 90°、复制/粘贴/再制、删除、对齐（左/右/上/下/水平居中/垂直居中/等距）、层级（置顶/置底/上移/下移）、锁定、属性面板（名称/位置/尺寸/旋转/图层/绑定对象/颜色/参数）、撤销/重做（Ctrl+Z / Ctrl+Y，≥50 步）、图层可见性/锁定、测量（尺寸标注）、文字标注、指北针/比例尺/图例/标题栏、导出 PNG/SVG/JSON、打印、快捷键帮助。
**联动要求**：选中绑定机柜/动环设备的图元时（或点击图元）`IDC.bus.emit('plan:select', {type:'rack'|'dh', ref})` 并调用 `IDC.scene.focusRack/focusDevice`；订阅 `dh:data`/`dh:alarm` 让绑定图元实时变色/显示值；点击动环页设备树或告警列表时也能 `IDC.plan.zoomToRef()` 高亮。

## 4. 3D 扩展接口（`src/scene3d.js`，viz-3d 实现）

```js
IDC.scene.setExtras(list)   // 用图纸里的图元生成/更新 3D 物件（覆盖式，传空数组=清空）
IDC.scene.clearExtras()
IDC.scene.focusExtra(id, {duration})   // 镜头定位到某个扩展物件
```
`list` 元素：`{ id, kind:'rack'|'ups'|'pdu'|'battery'|'ac'|'smoke'|'water'|'th'|'cctv'|'ext'|'door'|'wall'|'column'|'tray'|'sign'|'custom',
                  x, z, w, d, rot, name, level:'floor'|'ceiling'|'wall', status }`（x,z 单位**米**，由图纸 mm/1000 得到；w/d 为平面尺寸米；rot 度）
- 已知 kind 用现有 `PROPS.*`/机柜模型生成；`custom` 用灰盒 + 名称牌占位；
- 复用几何与材质、InstancedMesh 优先；`setExtras` 只增删差量、不重建全场景；
- 扩展物件支持点击 → `IDC.bus.emit('plan:select', {type:'extra', ref:id})`。
