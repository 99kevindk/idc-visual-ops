# 启动与故障排查（Windows）

## 正确启动方式
1. 双击项目根目录的 **`start.bat`**（必须和 `index.html` 放在同一层）。
2. 会弹出一个黑色控制台窗口，显示类似：
   ```
   URL: http://localhost:8123/
   Runtime: Node.js / Python / PowerShell built-in server
   ```
   **这个窗口要一直开着**（它就是服务本身，关掉窗口 = 服务停止）。
3. 浏览器会自动打开 `http://localhost:8123/`。若没自动弹出，手动在浏览器地址栏输入控制台里显示的 URL 即可。

## 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 浏览器显示"无法访问此网站 / 连接被拒绝" | ① 浏览器打开得比服务早（老版本脚本的 bug）——直接按 F5 刷新即可；② 控制台窗口被关掉了——重新双击 `start.bat`，并保持窗口开启 |
| 双击 `start.bat` 后窗口一闪而过 | 检查 `start.bat` 是否与 `index.html` 在同一目录；用右键"以管理员身份运行"排除权限问题；把窗口里最后的报错发我 |
| 提示端口被占用 | 启动器会自动顺延到 8124/8125…，看控制台里实际的 URL 就行（不要固定用 8123） |
| 控制台全英文 | 正常——批处理本体用纯 ASCII 以保证任何 Windows 都能跑 |
| 控制台中文乱码 | 属显示问题，不影响功能；`start.bat` 已 `chcp 65001`，若仍乱码可忽略 |
| 页面能开但**麦克风点了没反应** | 语音识别（Web Speech API）必须满足：① 地址是 `http://localhost:xxxx/`（不能是 `file://` 直接双击 index.html）；② 用 Chrome / Edge；③ 系统麦克风权限允许；④ 首次使用需允许浏览器访问麦克风 |
| 想不开浏览器只起服务 | 设置环境变量 `IDC_NO_BROWSER=1` 后再运行 `start.bat` |
| WSL / 局域网访问 | 服务只绑定 127.0.0.1（安全考虑），请在**本机**浏览器访问 |

## 没有 Node.js / Python 也能用
`start.bat` 的兜底路径是 **Windows 自带的 PowerShell 静态服务器**（`scripts/serve.ps1`），无需任何额外安装。

## 三种启动方式的区别
| 方式 | 语音识别 | 说明 |
|---|---|---|
| `start.bat` → `http://localhost:8123/` | ✅ 可用 | 推荐 |
| 直接双击 `index.html`（file://） | ⚠️ 不可用 | 3D、页面、文字指令、语音播报都正常，麦克风识别会自动降级为右侧输入框打字 |
| `npm run dev` | ✅ 可用 | 开发用（先 esbuild 打包再起服务） |

## 手动等价命令（排障时用）
```bat
:: Node
node scripts\start.mjs 8123
:: Python
py -3 -m http.server 8123 --bind 127.0.0.1
:: PowerShell（无需安装任何东西）
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\serve.ps1 -Port 8123
```
以上三条任选一条，看到 URL 后手动用浏览器打开同样可用。

# 动环（动力环境）网关

## 自动启动（推荐）
双击 `start.bat` 时会**自动**：
1. 在 **8123** 起静态服务（前端）；
2. 在 **8124** 起**动环网关**（`tools/gateway/server.mjs --driver sim`）；
3. 用 `http://localhost:8123/?gw=1` 打开浏览器 → 动环页显示「**已接入网关**」与 `ws://localhost:8124/dh`。

> 有 Node 才会自动拉网关；没有 Node 时前端仍完整可用（动环页显示「本地模拟」，用同一套点表跑数据）。

## 手动启动 / 换驱动
```bat
:: 默认内置模拟器
node tools/gateway/server.mjs --port 8124 --driver sim --poll 2000
:: 接真实设备（换驱动；无设备时 health 会如实报 error 与原因）
node tools/gateway/server.mjs --port 8124 --driver modbus-tcp
node tools/gateway/server.mjs --port 8124 --driver snmp
node tools/gateway/server.mjs --port 8124 --driver mqtt
npm run gateway
```

## 前端连接参数
| URL | 行为 |
|---|---|
| `http://localhost:8123/` | 默认**本地模拟**（不连网关，无多余网络日志） |
| `http://localhost:8123/?gw=1` | 自动连 `ws://<当前主机>:8124/dh`（start.bat 用的就是这个） |
| `?gw=ws://10.0.0.5:8124/dh` | 连指定网关地址 |
| `?gw=off` | 强制本地模拟 |
也可以在动环页右上角点「**接入动环网关 / 断开网关**」手动切换。

## 常见问题
| 现象 | 说明 |
|---|---|
| 动环页显示「本地模拟」而不是「已接入网关」 | 网关没起来或端口不是 8124。先看网关窗口有没有报错；或自行 `curl http://localhost:8124/dh/health` 确认 |
| 点「接入动环网关」时浏览器控制台出现 WS 连接失败 | 网关未运行时的正常现象（浏览器自身打印，非程序异常）；启动网关后会自动重连（每 12s 一次） |
| 8124 端口被占用 | 网关启动会失败（窗口里会有 EADDRINUSE）。换端口：`node tools/gateway/server.mjs --port 8125`，前端用 `?gw=ws://localhost:8125/dh` |
| 动环页没有数据 | 前端 `IDC.dh` 必定有数据（网关或本地模拟二选一）；若整页空白，F12 看是否有报错并发我 |
| 接真实设备要做的事 | 按厂家《通信协议手册》改 `src/pointtable.js` 的 `addr/oid/mqtt/scale/dtype/bits`（换厂家只改点表，不动代码），再切到对应驱动 |

## 点表与对点
- 导出：动环页右栏「导出 CSV」，或 `curl http://localhost:8124/dh/points.csv > 动环点表.csv`（260 行，含寄存器地址/SNMP OID/MQTT Topic/阈值）。
- 规范：`docs/动环接口规范.md`（可直接交厂家/集成商）。
